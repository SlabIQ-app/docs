# Available Integrations

## 🛒 eBay

SlabIQ integrates directly with eBay to help you import listings, track sales, and create optimized listing templates.

### What You Can Do

- Import active eBay listings
- Track sold items
- Sync pricing data
- Create reusable listing templates
- Push inventory directly to eBay _(if enabled)_

---

## Connecting Your eBay Account

Follow these steps to connect eBay:

1. Go to **Settings → Integrations **or select **Integrations** from the navbar.
2. Click **Connect eBay**
3. You will be redirected to eBay’s authorization page
4. Log in to your eBay account
5. Approve SlabIQ permissions
6. You’ll be redirected back to SlabIQ

Once connected, your eBay account will show as **Active**.

> 🔒 SlabIQ uses secure OAuth authentication. We never store your eBay password.

---

## Managing eBay Sync

After connecting:

- Enable or disable automatic sync
- Choose which listings to import
- Refresh sales data manually
- Disconnect your account anytime

---

## Creating Listing Templates

Listing templates allow you to create consistent, optimized listings quickly.

### To Create a Template

1. Navigate to **Integrations → eBay Listing Profiles**
2. Click **New Profile**
3. Fill in:
   - Profile Name
   - Payment Policy
   - Shipping policy
   - Return policy
   - Listing Type
   - Duration
   - Default Condition
   - Handling Time
   - Accept Best Offers or not
   - eBay Site (ebay us, ebay ca, etc)
   - Item Location
   - Postal Code
   - List Mode
4. Save your template

You can now apply this template when creating a new eBay listing from inventory.

---

## Applying a Template to a Listing

1. Create a Batch
2. Under list **Select Listing Template**
3. Adjust price and quantity
4. Publish

Your listing will be pushed directly to eBay.

# Troubleshooting

**eBay not syncing?**

- Ensure authorization has not expired
- Reconnect your account
- Check your plan supports marketplace features

**Template not applying correctly?**

- Verify required item specifics are filled
- Ensure pricing fields are populated
