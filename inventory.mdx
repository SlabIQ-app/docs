The **Inventory** settings allow you to **configure how items are managed, tracked, and listed** in SlabIQ.\
You can set **SKU formats, default values, and listing preferences** to standardize workflows and ensure consistency across your inventory.

---

## Key Features

- 🏷 **SKU Format:** Define how item SKUs are generated
- ⚙️ **Default Values:** Set default attributes for new inventory items
- 📋 **Listing Preferences:** Control how items are automatically prepared for marketplaces
- 🔄 **Batch Defaults:** Apply default settings for bulk inventory uploads

---

## SKU Format

- Customize the **structure of item SKUs** for easier identification
- Supports variables like:

| Variable      | Description                   |
| :------------ | :---------------------------- |
| {PLAYER}      | Player name                   |
| {TEAM}        | Team name                     |
| {YEAR}        | Card year                     |
| {SET}         | Set name                      |
| {CARD_NUMBER} | Card number (auto-prepends #) |
| {LOT}         | Lot or batch number           |

**Example SKU format:**

```
{PLAYER}-{YEAR}-{SET}-#{CARD_NUMBER}
```

- Generates SKUs like: `LeBron James-2023-Prizm-#23`

> ⚡ Tip: Standardized SKUs help with searching, reporting, and cross-listing.

---

## Default Values

- Set **default fields** for new inventory items to save time:

| Field        | Example Default |
| :----------- | :-------------- |
| Condition    | Mint            |
| Sport        | Basketball      |
| Manufacturer | Panini          |
| Graded       | No              |
| Rookie       | No              |
| Autographed  | No              |

- Applies automatically when adding **single items or batch uploads**

---

## Listing Preferences

- Configure **default listing settings** for marketplaces:

| Setting                      | Description                              |
| :--------------------------- | :--------------------------------------- |
| Default Marketplace          | eBay, Whatnot, etc.                      |
| Default Title Template       | Use variables and conditional formatting |
| Default Description Template | Auto-fill card details for new listings  |
| Price Margin                 | Default markup over cost                 |
| Listing Duration             | Auction or Fixed Price, e.g., 7 days     |

> ⚡ Tip: Pre-configuring these settings streamlines batch listing and reduces manual errors.

---

## Best Practices

- Define **SKU format before adding inventory** to maintain consistency
- Set default values for **most commonly used fields** to save time
- Configure listing preferences based on your **most-used marketplace**
- Periodically review defaults to reflect changes in inventory, pricing, or marketplaces

---

### Example Workflow

1. Navigate to **Settings → Inventory**
2. Set SKU format to `{PLAYER}-{YEAR}-{SET}-#{CARD_NUMBER}`
3. Set default **Condition: Mint**, **Sport: Basketball**, **Graded: No**
4. Set default **Title Template** for eBay listings
5. Save settings — new items and batch uploads will automatically follow these rules
