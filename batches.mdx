---
title: "Batches"
---

Batches allow you to group inventory items together for bulk processing, organization, or marketplace preparation.

Using batches helps you stay organized, work faster, and manage high-volume inventory more efficiently.

SlabIQ supports two types of batches:

- **Processing Batches** – For scanning and inventory workflows
- **Lot Builder Batches** – For grouped marketplace listings

Understanding when to use each type ensures the most efficient workflow.

---

# Processing Batches

Processing Batches are designed for inventory management and bulk workflows.

They are ideal when adding, scanning, or updating multiple items at once.

---

## Common Use Cases

- 📦 Grading submission returns (PSA, BGS, CGC, etc.)
- 🛍️ New collection purchases
- 📊 Bulk scanning sessions
- 🔄 Mass pricing updates
- 🏷 Applying tags to multiple items

---

## Creating a Processing Batch

1. Navigate to **Inventory → Batches**
2. Click **Create Batch**
3. Select **Processing Batch**
4. Enter a descriptive name\
   Example: `PSA Return – January 2026`
5. (Optional) Add notes
6. Click **Create**

Your batch is now ready to receive items.

---

## Adding Items to a Processing Batch

You can add items in multiple ways:

### During Scanning

When scanning new slabs, select the active batch before saving the item.

### From Existing Inventory

1. Select one or more items
2. Click **Move to Batch**
3. Choose the target batch
4. Confirm

---

## Bulk Actions Within a Processing Batch

Inside a batch, you can:

- Edit multiple items at once
- Update pricing in bulk
- Apply tags
- Export selected items
- Move items to another batch
- Archive when complete

> 💡 Processing Batches are recommended when handling 5 or more items.

---

## Batch Status Tracking

To stay organized, batches can be marked as:

- 🟡 Draft
- 🔵 Processing
- 🟢 Completed
- 🔴 Archived

Updating batch status helps track your workflow progress.

---

# Lot Builder Batches

Lot Builder Batches are designed specifically for grouped marketplace listings.

Instead of listing items individually, you can combine multiple inventory items into a single lot.

This is ideal for:

- Team lots
- Player lots
- Set bundles
- Clearance bundles
- Value groupings

---

## Creating a Lot Builder Batch

1. Navigate to **Marketplace → Lot Builder**
2. Click **Create New Lot**
3. Select inventory items to include
4. Enter a lot name\
   Example: `2024 Prizm Football Rookie Lot – 10 Cards`
5. Save

Your lot is now ready for listing preparation.

---

## What Lot Builder Does

Lot Builder:

- Groups multiple inventory items into one listing
- Calculates combined valuation
- Applies saved listing templates
- Generates optimized title structure
- Prepares the lot for marketplace publishing

Lot Builder is focused on selling strategy rather than internal organization.

---

## Publishing a Lot to eBay

If your eBay account is connected:

1. Open the Lot Builder batch
2. Click **Create Listing**
3. Select a saved listing template
4. Adjust pricing and shipping details
5. Publish

The lot will be listed as a single grouped item on eBay.

---

# Processing Batch vs Lot Builder

| Feature                   | Processing Batch | Lot Builder |
| :------------------------ | :--------------- | :---------- |
| Bulk Scanning             | ✅                | ❌           |
| Workflow Organization     | ✅                | ❌           |
| Bulk Editing              | ✅                | Limited     |
| Marketplace Group Listing | ❌                | ✅           |
| eBay Publishing           | Optional         | Primary Use |
| Inventory Structuring     | ✅                | Secondary   |

---

# Archiving Batches

When a batch is complete:

1. Open the batch
2. Click **Archive**
3. Confirm

Archived batches remain searchable but are removed from active views.

---

# Best Practices

✔ Name batches clearly using date + purpose\
✔ Use Processing Batches for grading submissions\
✔ Use Lot Builder for sales strategy\
✔ Avoid mixing unrelated categories in lots\
✔ Archive completed batches to keep your dashboard clean

---

## Example Naming Structures

Processing Batch:\
`PSA – February 2026 – 35 Card Submission`

Lot Builder:\
`2023 Optic Basketball – Rookie Lot – 12 Cards`

---

# When Should You Use Each?

Use **Processing Batches** when:

- You are adding or updating multiple items
- You are organizing workflow stages
- You need bulk inventory management

Use **Lot Builder** when:

- You want to sell multiple items together
- You are bundling lower-value items
- You want to reduce listing fees
- You are creating themed sales groups

---

# Pro Tips

- Larger lots may reduce per-item marketplace fees
- Bundled lots often move slower but increase total order value
- Use consistent listing templates for branding
- Track lot performance in Analytics to refine strategy
