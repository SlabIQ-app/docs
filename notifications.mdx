---
title: "Notifications"
---

The **Notifications** section allows you to manage how SlabIQ communicates with you.\
You can configure alerts for sales, inventory changes, cross-listing, promotions, and system updates, ensuring you stay informed while keeping your inbox or phone clutter-free.

---

## Key Features

- 📧 **Email Notifications** – Alerts sent to your registered email
- 📱 **SMS Notifications** – Optional text message alerts for critical updates
- 🔔 **In-App Notifications** – Notifications displayed directly in the SlabIQ dashboard
- ⚙️ **Customizable Alerts** – Choose which events trigger notifications

---

## Available Notification Types

| Notification         | Description                                  | Default  |
| :------------------- | :------------------------------------------- | :------- |
| Sale Completed       | Alert when an item is sold                   | Enabled  |
| Inventory Aging      | Alert when items exceed aging thresholds     | Enabled  |
| Cross Listing Status | Alert for listing failures or updates        | Enabled  |
| Pick List Updates    | Alert when items are awaiting shipping       | Enabled  |
| Marketplace Sync     | Alert when a connected account fails to sync | Enabled  |
| Promotions & Updates | Announcements or system updates              | Optional |

---

## Managing Notifications

1. Navigate to **Settings → Profile → Notifications**
2. Toggle **ON / OFF** for each notification type
3. Choose delivery method: Email, SMS, or In-App

> 💡 Tip: Enable **critical alerts** like sales, inventory aging, and pick list updates to ensure smooth operations.

---

## Best Practices

- Enable **sale and shipping notifications** to stay on top of orders
- Use **inventory alerts** to manage slow-moving items proactively
- Disable non-essential alerts to avoid notification fatigue
- Review notification settings after adding new marketplace integrations

---

## Example Workflow

1. Enable **Sale Completed** alerts via email and SMS
2. Turn on **Inventory Aging** alerts for items over 90 days
3. Receive notifications for **Pick List updates** to streamline fulfillment
4. Review notifications in-app or export reports as needed
