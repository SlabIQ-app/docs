title: "Security"

The **Security** section allows you to manage your **account access and protection settings**.\
Keeping your account secure ensures that your inventory, sales data, and personal information are safe.

---

## Key Features

- 🔒 **Change Password:** Update your login password to maintain account security
- 🛡 **Two-Factor Authentication (2FA):** Add an extra layer of protection to your account
- 📧 **Login Alerts:** Receive notifications for new device logins or suspicious activity
- 🗑 **Active Sessions:** View and manage all devices currently logged into your account
- ⚙️ **API Key Management:** Generate or revoke API keys for integrations

---

## Changing Your Password

1. Navigate to **Settings → Profile → Security → Change Password**
2. Enter your **current password**, then your **new password**
3. Confirm the new password and click **Save**

> 💡 Tip: Use a strong, unique password and update it periodically.

---

## Two-Factor Authentication (2FA)

- Add **2FA** via an authenticator app (e.g., Google Authenticator)
- Once enabled, you’ll need a temporary code on login
- Protects your account even if your password is compromised

---

## Login Alerts

- Receive **email or SMS alerts** for:
  - New device login
  - Suspicious login attempts
- Helps detect unauthorized access quickly

---

## Active Sessions

- View all devices currently logged in
- End sessions remotely if a device is lost or compromised
- Track last login date, device type, and IP address

| Device  | Last Login | Location           | Action  |
| :------ | :--------- | :----------------- | :------ |
| Desktop | 02/18/2026 | New York, USA      | Log Out |
| iPhone  | 02/19/2026 | San Francisco, USA | Log Out |

---

## API Key Management

- Generate API keys for external integrations (marketplaces, analytics, or custom tools)
- Revoke keys at any time to prevent unauthorized access
- Label keys for easy identification

> ⚡ Tip: Only share API keys with trusted applications and rotate keys regularly.

---

## Best Practices

- Enable **2FA** to protect against unauthorized access
- Regularly review **active sessions** and log out unused devices
- Update passwords periodically with **strong, unique credentials**
- Monitor **login alerts** to detect suspicious activity
- Manage API keys carefully to prevent security breaches
